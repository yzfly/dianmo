## 1. 设计原则（对齐字节系产品）

- **克制、清爽**：
  - 大量留白，配色只用一个品牌主色（图标的蓝→紫→品红渐变只用在品牌位，界面主色用蓝 `#3B6CF6` 一类），其余是中性灰。
  - 圆角统一：卡片 12，按钮 8，开关为胶囊形。
  - 字号层级清楚：标题 20，分组标题 13 灰，正文 15，说明 12 灰。
- **每个设置都有一句说明**，不用术语，例如「点输入框时自动弹出键盘」，而不是「UIA 焦点监听」。
- **即改即生效**，没有「应用 / 确定」按钮；危险操作（清空剪贴板历史、恢复默认）要二次确认。
- **状态可见**：
  - 语音引擎、词库、开机自启、管理员模式这些状态，用绿点表示正常、黄点表示需要处理，并附上一句原因。
  - 有问题的地方给出「一键修复」按钮，而不是只报错。
- **深浅色都要做好**；跟随系统，也可以手动切换。
- **触屏优先**：设置窗口里所有可点的元素都不小于 44 DIP，可以用手指滚动，不依赖右键和悬停。

## 2. 产品部件清单

| # | 部件 | 内容 | 验收 |
|---|---|---|---|
| P1 | **安装** | `点墨-安装.exe`（或带 `--install` 的单个 exe）：安装到 `%LOCALAPPDATA%\Dianmo`；建桌面和开始菜单快捷方式；注册计划任务（最高权限）；在「应用和功能」里登记卸载项（含图标、版本、发布者「云中江树」）；装完自动启动并弹出欢迎页 | 在一台干净的 Windows 上双击就能装好，不需要命令行 |
| P2 | **卸载** | 在「应用和功能」里卸载，或运行 `dianmo.exe --uninstall`：退出点墨；恢复系统键盘设置；删掉计划任务、快捷方式和程序目录；询问是否保留用户数据（词库、设置、固定的剪贴板） | 卸载后不留残余，系统设置都恢复原样 |
| P3 | **首次启动引导** | 3–4 屏卡片：①欢迎（品牌和一句话介绍）②选默认布局（全拼 / 小鹤 / 九宫格，附示意图）③选语音引擎（检测已安装的引擎，推荐一个）④几个常用手势（长按空格是触控板、上滑出符号、悬浮球）。每屏都能跳过，以后可以在「关于」里重看 | 第一次安装后自动出现，只出现一次 |
| P4 | **设置窗口** | 普通的 Windows 窗口（可激活、可最小化，有任务栏图标），左侧是导航，右侧是内容。从托盘「设置…」、键盘工具栏的 ⚙ 和开始菜单都能打开。分页见 §3 | 每一项都能改，改完立即生效，重启后保留 |
| P5 | **关于** | 设置窗口的最后一页：图标、名称、版本、构建日期、一句口号；**开发者：云中江树**；项目主页和源码（GitHub）、开源许可证（GPL-3.0）、第三方组件致谢（librime、雾凇拼音 rime-ice、OpenCC、windows-rs 等）；按钮：检查更新、反馈问题、重看引导、打开日志目录 | 信息齐全，链接都能打开 |
| P6 | **检查更新** | 从 GitHub Releases 读取最新版本：有新版时托盘显示小红点，设置里显示更新说明，点一下下载并静默升级（关掉旧版→替换→重启）；可以关闭自动检查 | 不常驻：启动后 1 分钟检查一次，之后每天最多一次 |
| P7 | **反馈** | 「反馈问题」打开 GitHub Issues 的新建页，预先填好版本、系统版本、屏幕和缩放信息；也可以「导出诊断包」（日志和设置打成 zip，不含剪贴板和词库内容） | 用户不用自己去找日志 |
| P8 | **托盘菜单** | 整理成：显示/隐藏键盘、布局 ▸、语音引擎 ▸、语音模式、设置…、关于点墨、退出。不常用的项（高度、主题、编辑区）挪到设置里 | 不超过 10 项 |
| P9 | **提示与错误** | 统一的轻提示（键盘上方的胶囊，1–2 秒后消失）和设置里的状态条；不弹系统对话框 | 全程没有 MessageBox |
| P10 | **README 和发布** | README 包含：一句话介绍、截图（键盘浅色/深色、宽屏、九宫格、电脑键盘、剪贴板、悬浮球、设置、关于）、功能列表、安装、使用技巧、常见问题、从源码构建、致谢、许可证、开发者。GitHub Release 附安装包和更新说明 | TODO #34 |

## 3. 设置分页

1. **常规**
   - 开机自动启动
   - 点输入框时自动弹出键盘
   - 语音模式（只显示悬浮球）
   - 外观：跟随系统 / 浅色 / 深色
   - 管理员窗口支持：显示状态，未注册时给「修复」按钮
2. **键盘**
   - 默认布局（全拼 / 小鹤 / 九宫格 / English / 电脑键盘）
   - 键盘高度（滑块）
   - 横屏显示编辑区
   - 按键气泡
   - 按键音（以后做，先留位置）
   - 长按时长（短 / 中 / 长）
   - 悬浮球：开关；靠左 / 靠右
3. **输入**
   - 候选字号
   - 中文时用全角标点
   - 空格上屏首选
   - 模糊音（z/zh、c/ch、s/sh、n/l、an/ang、en/eng、in/ing）：要写进 rime 方案，第一版可以只做开关和说明，第二版接通
   - 双拼方案（小鹤，以后加自然码、微软）
   - 用户词库：导出、导入、清空
4. **语音**
   - 语音引擎：微信输入法 / 豆包语音 / 系统。每个都显示检测状态，没装的给出下载链接
   - 失败时自动改用系统语音
   - 豆包语音的程序路径
5. **剪贴板**
   - 记录剪贴板历史
   - 条数上限
   - 不记录密码框里的复制
   - 清空历史（二次确认）
   - 固定的条目
6. **关于**：见 P5。

## 4. 实现分工（2026-10-06）

- **dianmo-win**：通用的「应用窗口」宿主。普通窗口，可激活，有标题栏（或自绘），支持 DPI、鼠标 / 触摸 / 滚轮 / 键盘、`Canvas` 绘制，复用 dianmo-ui 的 `View` 契约。另外提供在键盘进程里打开、关闭设置窗口的接口。
- **dianmo-ui**：
  - 设置界面组件库：导航栏、分组卡片、开关、分段选择、滑块、按钮、状态点、链接；
  - `SettingsView`（各分页）、`AboutView`、`OnboardingView`；
  - 预览图用 `examples/preview.rs` 生成。
- **dianmo**：
  - 设置模型：把 settings.ini 和计划任务、注册表这些系统状态统一读写，即改即生效；
  - 安装和卸载（P1 / P2）、检查更新（P6）、反馈（P7）、托盘整理（P8）。
- **文档**：README、截图、Release（P10）。
